# Arvectum Golden Step v0.85 — возвращение к Inter

22.11.2026 | Company / BR-05 | Эксперимент, не утверждён для релиза.

## Решение по художественному направлению
Три самостоятельно построенные формы «З/з» из v0.84 отклонены собственником. Новая исходная точка — подлинные немодифицированные контуры Inter 4.1 из v0.36; каждую букву далее развиваем отдельно в контексте концепции Arvectum. Ни один из вариантов v0.84 не перенесён.

## Комплект
- Два черновых OTF: Display Medium и Text Regular, источник — InterDisplay-Medium / InterDisplay-Regular 4.1.
- Все 2 852 Unicode-позиции и 2 937 глифов каждого источника, **0 изменённых контуров**, сохранены метрики и исходный кернинг.
- SVG для «З, з, 3, В, в, А, Е, М», сравнительный векторный PDF с примерами 12–48 px.
- GLYPH-REVIEW-LEDGER.csv: 128 латинских/кириллических букв и цифр с отдельным статусом; ни одна пока не утверждена как авторская.
- Лицензия Inter SIL OFL 1.1 и проверяемое происхождение бинарных файлов, генератор и QA.

## Принцип развития
1. Сначала З/з: оригинал Inter против **одной** точечной авторской коррекции, проверить форму, терминалы, контрформы, отличимость от 3, набор в кириллице и 12/16/24/48px.
2. После художественной оценки продолжать В/в/B, Б/б, Р/р, Ь/ь и остальные буквы **поштучно**, не применять массовый алгоритм к дугам.
3. Фирменные диагонали могут опираться на arctan(φ)≈58,2825°, но оптическая читаемость важнее механического подчинения каждой кривой математике.
4. Логотип, Wordmark, сайт, клиентские материалы, шрифты предыдущих версий и Windows не меняются.
