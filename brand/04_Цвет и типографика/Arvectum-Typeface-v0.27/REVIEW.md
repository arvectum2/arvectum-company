## Наблюдение и метод
В исходном m v0.26, при y=600/900 от x-height, Display имеет просветы 310.8175 / 502.4087, Text — 341.13 / 517.565. Это геометрические единицы рабочих SVG, не font units утвержденной гарнитуры. У n/h при общей ширине 945 просвет равен 543.81746 Display / 574.13 Text. h использует тот же контур, кроме выносного штриха.
Вариант A-fixed сохраняет общую ширину m=1415, выравнивает просветы; B-80pct задает каждому просвету 80% n, ширина увеличена. Внутренние кривые обоих просветов — масштабированные по x внутренние кривые n, вертикальные координаты и толщины штрихов сохранены. Верхний внешний контур v0.26 преобразован по частям, не утвержден как окончательный.

## Проверка
Четыре SVG, 96 точек аппроксимации на кубическую кривую, отсутствие строгих несмежных пересечений, положительная площадь, границы x, равенство внутренних просветов на срезах y=250/300/400/600/900 (при наличии внешней выемки она исключается из сравнения). Не доказывает отсутствие всех касаний, финальную оптику, кернинг и production-пригодность. geometry.json — измерения и SHA256; build.py — воспроизводимый источник. proof.svg / proof.png — сравнение на общих масштабах, в том числе малом размере; интервалы демонстрационные, не шрифтовые метрики.
Визуальная вычитка: у A/B внутренние просветы явно равномернее прежних; внешний силуэт плеч всё ещё асимметричен, в месте соединения сохраняется выраженная выемка. Предпочтение для следующей пробы: A для Display (компактность), B для Text (более открытые просветы); это рабочая рекомендация, не утверждение.
