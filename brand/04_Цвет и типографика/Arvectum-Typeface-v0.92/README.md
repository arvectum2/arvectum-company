# Arvectum Golden Step v0.92 — corrected A/А, both masters evolve

**Experimental candidate, no production approval.** 22 November 2026.

The user corrected two critical mistakes:
1. Approved wordmark A/А breaks on the **RIGHT**, anchored LEFT. v0.91 left break was wrong. In this version Display has a right gap 230 units, with 371/601 of the original lower bar retained (≈1/φ).
2. Inter is ONLY the source of Arvectum Display AND Arvectum Text, not an accepted final Text face.
