# Arvectum Typeface v0.35 — интеграционная карта и независимый выбор е/р
2026-11-20 | Draft / owner review | BR-05
Матрица 2×2: K (тонкая перекладина + промежуточная чаша), M (тонкая + сбалансированная), N (открытая + промежуточная), L (открытая + сбалансированная). M/N — новые сочетания существующих контуров, не новые формы и не утверждение. Сохранены C v0.21, монограмма и соседние контуры/позиции. L — предварительная рекомендация v0.34.
Manifest: 236 буквенных позиций; 28 актуальных кандидатов обоих начертаний, 26 legacy, 20 только wordmark, 162 без отдельного исходника. 54 отдельных контура сверены с SHA256 v0.31. Для e/е/р — отдельная ссылка на контекстный L, не перенос в Display/Text. Покрытие не увеличилось. Coverage SVG — индивидуально вписанные глифы, не проверка общего масштаба или интервалов.
Проверка: сохранены атрибуты и геометрия неизменённых букв и монограммы; K/L эквивалентны v0.34, 16 SVG прочитаны повторно, 3 контрольных SVG валидны как XML. M/N используют ранее проверенные контуры без сдвига. Оригиналы v0.13/v0.23/v0.24 недоступны, повторный поиск Library не дал ZIP. Полная сборка, кернинг, OpenType, печать открыты. Следующая точка — решение по е/р и восстановление полной базы. Production не изменён.
PNG selection-proof.png (1600×1040) отрисован Chromium, проверены размер и непустой растр; визуально сопоставлены четыре комбинации, логоблоки EN/RU и уменьшенные образцы. Разница тонкая; L остаётся предпочтением по открытости е, не утверждением. На листе отдельные глифы индивидуально вписаны, поэтому их размеры нельзя использовать как метрическое сравнение.
