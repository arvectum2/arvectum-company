22 November 2026. **Synthetic local demo only, not a live company or client document.**

Two independently developing Arvectum Display and Text fonts are compared on identical historical mockups (letter A4, proposal A4, mobile 390px). The only variable between old v0.104 and new v0.105 is each local WOFF2 font URL. Approved logo SVG and source HTML/CSS layouts remain byte-equivalent.
