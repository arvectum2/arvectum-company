# Arvectum AI Continuity — offline starter kit 0.1 (candidate)

Contains no real chat exports, credentials or customer data. The import prototype is tested with synthetic ZIPs only; actual OpenAI ZIP structure and coverage must be verified upon delivery. Run on the owner's trusted computer using Python 3.10+ (standard library only). No network, APIs, package installation or account needed.

1. Download and retain the original export ZIP in encrypted private storage. Do not send it to an AI/cloud provider or commit it to Git. Use a private encrypted directory for all derived files; the script does not implement encryption. Keep an independent encrypted backup of the original. Confirm adequate free disk space.
2. Run `python3 -m unittest -v` inside this directory to test the kit without accessing real data.
3. Run `python3 import_export.py /path/to/export.zip /path/to/private/new-import` (output directory must not exist; its parent must exist). It calculates SHA-256 of the original, reads ZIP members without extracting them, records each file's hash, indexes recognized conversation nodes in SQLite, retains branches and raw node JSON, and records parsing gaps. It never changes the original ZIP. Supported candidate names: `conversations.json`, `conversations-001.json`, `conversations_001.json`. Root must be a list of records with a `mapping` object. Other structures and missing content remain unresolved; the manifest is not a claim of full account coverage. Oversized JSON needs a separately reviewed streaming parser. The prototype does not reconstruct attachments, project membership, custom instructions, memory, automations, timestamps/UI ordering or exact visible chat threads; keep the original ZIP. No deduplication across different conversation source records.
4. Local search: `python3 search_history.py /path/to/private/new-import/history.sqlite 'поисковая фраза' --limit 10`. This is case-insensitive substring search across message text and conversation titles, not semantic search. Output may contain sensitive historical data. Do not paste blindly into a model; review and redact first. No execution of archived tool calls.
5. Use BOOTSTRAP.md and HANDOFF.template.json as a redacted starting point for another authorized model. Review current canonical Company sources and fill missing fields. This is not a dump of all account memory or a binding policy.

Candidate acceptance: inspect actual archive formats and manifest; sample branches and missing attachments; prove restore from independent storage; independently test one permitted workflow without ChatGPT. Do not activate restored automations automatically. Preserve original schedule, last-run evidence and prior disabled state; reconcile with existing external scheduler before enabling anything.
